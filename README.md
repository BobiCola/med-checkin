# 吃药打卡 v2.0

一款本地服药打卡 Android App：设定每天几点吃药，到点提醒，按时间段打卡，并提供完整的服药统计。

- 技术栈：Kotlin + Jetpack Compose + Material 3 + Room + Glance
- 系统要求：Android 8.0（API 26）及以上，targetSdk 35
- 数据完全保存在本机，不联网

## 下载

在 [Releases](../../releases) 下载最新的 `med-checkin-release.apk` 安装即可。

## 功能

### 打卡
- 首页蓝色渐变头图 + 今日进度环，圆形大打卡按钮自动选中当前时间段内最早一次未打卡的服药。
- 打卡时间段：每次服药可在「设定时间 - 提前分钟 ~ 设定时间 + 延后分钟」内打卡（默认前 30 / 后 60 分钟），全局设置，也可按药品单独设置。
- 状态：待服 / 准时 / 迟到 N 分钟 / 漏服 / 已跳过；未到时间显示倒计时。
- 支持跳过、撤销、补卡（实际时间须在时间段内）和备注；防连点。
- 桌面小组件：显示今日进度和下一次服药，可直接打卡。

### 提醒
- 到点通知，通知内可直接「已吃」打卡，支持稍后 10 / 30 分钟提醒。
- 未打卡时重复提醒，超出打卡时间段后停止。
- 声音 / 振动可选；开机、升级、修改时间或时区后自动重新设定提醒。

### 统计
- 日视图：任意日期每次服药的计划时间、实际时间和状态。
- 月历热力图：按完成度着色。
- 药物总览：记录天数、已服、漏服、跳过、准时率、连续全勤天数、近 7 / 30 天完成率柱状图、平均延迟和各时段漏服率。
- 导出 CSV、PDF 报告和长图。

### 设置
- 多种药品，新增药品向导（基本信息 → 服药时间 → 疗程频率 → 库存），默认早 08:00 / 中 12:00 / 晚 20:00，24 小时制时间选择。
- 疗程：起止日期或天数；频率：每天 / 每 N 天 / 每周指定几天。
- 库存：打卡自动扣减、撤销恢复、低库存提醒。
- 迟到阈值、打卡时间段设置。
- 每日计划快照：修改服药时间不影响历史统计。
- JSON 备份与恢复。
- 深色模式跟随系统。

## 构建

需要 JDK 17 和 Android SDK（platform 35、build-tools 35）。

```bash
./gradlew testDebugUnitTest   # 单元测试
./gradlew assembleRelease     # 发布版 APK
```

发布版签名：在 `keystore/` 目录放入 `release.jks` 和 `keystore.properties`（storeFile / storePassword / keyAlias / keyPassword）。签名文件不在仓库中，请自行妥善保管；必须使用同一签名才能覆盖安装升级。

也可以用 Android Studio 打开本目录直接运行。
